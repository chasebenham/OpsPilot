# Process comparison

Manual intake involves a person reading, classifying and routing a request. AI-assisted intake adds an advisory model response and explicit human review. Automated routing adds deterministic routing and, where applicable, approval or task rules; human approval remains required. Each can fail through incomplete input or human error; AI adds extraction and classification errors, while deterministic rules can encode incorrect assumptions. These are process descriptions, not measured time trials.

Active handling, elapsed cycle time, provider latency, approval wait and project execution time are different quantities. The illustrative financial calculator uses user-supplied active handling assumptions only. It does not measure elapsed time or claim observed savings. The workspace exports the qualitative comparison, but a timed comparison experiment is not yet implemented.

For future trials, record task start and finish for each human separately from API latency, approval wait and end-to-end elapsed time. Compare matched synthetic scenarios and report sample size and exceptions. Current manual handling inputs are assumptions; no human timing trial has been conducted.

The Evaluation Lab reports measured provider-call latency for explicitly run synthetic cases. It is not staff handling time, approval wait, end-to-end elapsed time, or an observed productivity benefit. Workflow records are simulated behavior. Business Impact uses assumptions to project productivity; the projection is not observed real-world savings.
